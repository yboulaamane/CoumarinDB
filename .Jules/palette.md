
## 2024-05-24 - Invalid Interactive Elements & External Repository Links
**Learning:** Found nested interactive elements (`<button>` tags containing `<a>` tags) in the download section. This causes significant issues for keyboard and screen reader accessibility because nested interactive elements result in ambiguous focus and activation semantics. Additionally, linking directly to raw GitHub blob URLs for file downloads is poor UX, as it unnecessarily directs the user out of the site (or relies on GitHub to enforce download behavior) and increases dependency on external infrastructure, while ignoring relative path references.
**Action:** Replaced the invalid button/link nesting with proper `<a>` tags styled to look like buttons (using the newly created `.download-btn` CSS class). Replaced the absolute GitHub URLs with relative paths and utilized the HTML5 `download` attribute to force direct file download, keeping the user in context and avoiding external round-trips.
