## 2024-05-14 - Fix Invalid Nested Interactive Elements (button > a)
**Learning:** This app used invalid HTML by nesting `<a>` tags inside `<button>` elements for its download links. This breaks keyboard accessibility as screen readers and keyboard navigation get confused by nested interactive elements.
**Action:** Replaced the `<button>` tags with semantic `<a>` tags styled using a custom CSS class `.download-btn` that provides `display: inline-block`, `padding`, and background colors to visually resemble buttons. Crucially, added `:hover` and `:focus-visible` pseudo-classes to restore the visual interactive feedback that native buttons provide, and ensured `rel="noopener noreferrer"` was included for `target="_blank"` links to prevent reverse tabnabbing. Also fixed a structural issue where references were outside the `</body>` tag.
