## 2024-04-16 - [Semantic Download Buttons]
**Learning:** Replacing nested `<a>` inside `<button>` with semantic `<a class="download-btn">` improves accessibility, keyboard navigation, and enables native HTML5 downloads using relative local file paths.
**Action:** Always use styled semantic `<a>` tags for download links with `display: inline-block` and `:hover`/`:focus-visible` states to preserve interactive feedback.
