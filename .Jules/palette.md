## 2024-05-13 - Fix accessibility and UX for download links\n**Learning:** Nested interactive elements like `<button><a>` are invalid HTML and confusing for screen readers. Absolute GitHub blob URLs in `<a>` tags don't respect the HTML5 `download` attribute (forcing users to navigate to GitHub instead of downloading directly).\n**Action:** Use semantic `<a>` tags styled as buttons (using CSS classes instead of inline styles) for downloads. Provide relative URLs and the `download` attribute to ensure files are saved directly without navigating away, and define focus states for keyboard accessibility.
