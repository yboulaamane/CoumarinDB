## 2024-05-18 - Semantic Anchor Tags vs Nested Elements
**Learning:** In simple HTML documents, interactive elements often use incorrect nesting (like placing `<a>` inside `<button>`) or inline styles to achieve a button-like appearance. This creates accessibility issues and broken behaviors (e.g. `download` attribute not working properly). Furthermore, using absolute URLs for project-local assets creates unnecessary network dependency and circumvents the purpose of the `download` attribute, which requires same-origin URLs in modern browsers.
**Action:** Always refactor to use semantic `<a>` tags with `class="download-btn"` for links that look like buttons, ensuring proper hover/focus-visible styles. Convert absolute repository asset URLs to relative paths to improve performance and allow the `download` attribute to function properly without triggering new tabs.
